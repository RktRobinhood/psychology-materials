Stage 1 · Sensory memory

Sperling: what is still there after the image is gone?

The central problem is not simply “How many letters can you remember?” It is whether more information is briefly available than you can report before it fades.

Before you participate

The question Sperling was trying to solve

If nine letters appear for only a fraction of a second, people usually report only a few. That result alone is ambiguous. Perhaps the visual system encoded only those few letters. Or perhaps most of the display was briefly present, but the trace faded while the participant was trying to report it.

Whole report asks for everything you can remember. Partial report changes the logic: after the display has disappeared, a tone tells you which row to report. If you can report almost any row when it is cued immediately, then information from the whole display must have been available for a very short time.

Important mindset: do not wait until you have a confident, verbal memory of a letter. The flash is too brief to inspect the grid letter-by-letter or deliberately rehearse it. As soon as it disappears, type whatever seems to be left—even a fragment you are only partly sure about. A weak, fading impression is exactly what this task is trying to catch.
The original displays were extremely brief. This browser version defaults to 100 ms for classroom reliability; the teacher can change it in settings. The important manipulation is the contrast between whole report and a row cued after the display.

What will happen first?

You get two guided practice flashes: one deliberately slow example, then a shorter transition flash so the true speed is not a shock. Nothing measured begins until you explicitly say you are ready. Every measured trial follows the same rhythm: ready → countdown → fixation → flash → response → feedback.

Part A · Whole report
  1. Read the instructions.
  2. Press “I’m ready.”
  3. Use the fixation cross to settle your eyes.
  4. The 3×3 array flashes.
  5. Type any letters you remember.
  6. Check your score, then choose the next trial.

Eight measured whole-report trials follow the two practice flashes. Low scores are normal; the aim is to notice what remains before it fades.

Part B · Partial report

Now the cue arrives after the display

This is the critical change. You still do not know which row matters while the letters are visible. Only after the grid disappears will a tone tell you which row to report.

If the whole display leaves a rich but rapidly fading iconic memory, an immediate tone should let you sample one row quite accurately. If the tone is delayed, that advantage should shrink as the visual trace decays.

Do not overthink the report. You cannot know which row will be requested until after the display is gone. When the tone sounds, enter whatever letters from that row seem to still be present—even if the trace feels vague.

Learn the cue

Use the buttons as many times as you need before the practice trial. The tones are intentionally far apart in pitch. Check your device volume now rather than during a measured trial.

What changes?
  1. Same brief grid.
  2. Grid disappears.
  3. A tone arrives after a short delay.
  4. Report only the requested row.
  5. Later, compare performance across cue delays.

Measured trials mix several cue delays so you cannot anticipate them.

Your evidence

Was more available than you could report?

Compare your average whole-report score with the amount implied by immediate partial report. One person is noisy evidence; the class pattern matters more.

Interpretation

Partial-report “estimated available” = row accuracy × 3. This illustrates Sperling's logic rather than providing a laboratory estimate.

Optional extension · Echoic memory

Can an auditory trace be disrupted?

Echoic memory is the auditory counterpart of iconic memory. This short extension uses the suffix effect: you hear a digit sequence, then sometimes an irrelevant spoken “zero” immediately after it. The suffix can interfere disproportionately with the final items.

This is not a reproduction of Darwin, Turvey & Crowder's three-channel partial-report experiment. It is a simpler browser-safe demonstration of a fragile auditory trace.

Stage 2 · Short-term memory

How much can be held without durable storage?

Short-term memory in the multi-store model is limited in both duration and capacity. This lab makes capacity visible—and then shows why “items” are not as simple as they sound.

Capacity

The famous “7 ± 2” claim

Miller's “magical number seven, plus or minus two” is often introduced as a rough historical description of immediate-memory capacity. You will test your own ordered digit span, beginning with five digits and increasing when recall is exact.

The result should not be treated as a fixed biological limit. Chunking changes what counts as an item, familiarity matters, and modern working-memory accounts are more complex than a single number.

Digits appear one at a time. Each trial waits for you, gives a countdown, and then begins. No writing or screenshots.
What to notice
  1. At what length does exact ordered recall become unreliable?
  2. Do near-misses still preserve many positions?
  3. Does grouping change the subjective difficulty?
Chunking

Now make “capacity” less tidy.

You will briefly see an eight-digit Danish-style number and a ten-digit Canadian-style number, then hold each for ten seconds before typing it. The number of digits differs, but familiar grouping can compress several digits into larger units.

This is why psychologists distinguish the raw number of symbols from the number of meaningful chunks.

Prediction

Before you start, decide whether the ten-digit number must necessarily be harder simply because it contains more digits.

Your evidence

Your short-term-memory pattern

What supports the model?

Immediate ordered recall becomes fragile as the amount of information increases. That is consistent with a capacity-limited short-term store.

What complicates it?

Capacity depends on how information is represented. Chunking can turn several symbols into one meaningful unit, so “7 ± 2 items” is not a simple count of characters.

Stage 3 · STM and LTM

Serial position: one list, two memory systems?

The beginning and end of a list are often remembered better than the middle. Glanzer and Cunitz used a filled delay to ask whether the two ends depend on different processes.

Serial-position experiment

Primacy and recency

Primacy is better recall for early items. In a multi-store interpretation, early items receive more opportunity for rehearsal and entry into long-term memory. Recency is better recall for the final items, which may still be active in short-term memory when recall begins.

You will see two 15-word lists using the same timing. After the first list, recall begins immediately. After the second, you must complete a 30-second arithmetic distractor before recall. If recency depends on short-term memory, the filled delay should selectively weaken the final items.

This takes several minutes because the timing is part of the manipulation. Nothing begins until you press the ready button, so settle yourself before each list.
Design
  1. 15 items, presented one at a time.
  2. Free recall: order does not matter.
  3. Second list uses the same schedule.
  4. 30 s filled delay blocks rehearsal.
  5. Compare early, middle, and final positions.

The arithmetic task is a silent classroom adaptation of a filled distractor.

Your evidence

Did the delay selectively reduce recency?

Your individual curve may be messy. Focus on the logic: a filled delay should remove the immediate advantage for the most recent items more than it removes primacy.

Stage 4 · Alternative account

Levels of Processing: perhaps encoding matters more than stores.

Craik and Lockhart shifted the question from “Where is the memory stored?” to “What kind of processing happened when it was encoded?”

Before you participate

This is not a fourth memory store.

Levels of Processing is an alternative way of explaining later memory. Instead of assuming that rehearsal moves information from short-term to long-term storage, the approach proposes that deeper, more meaningful processing creates a more durable memory trace.

Craik and Tulving operationalized depth with different orienting questions. A question about a word's visual appearance requires relatively shallow processing; a rhyme question requires attention to sound; a meaning question requires semantic processing.

LevelTypical questionProcessing
StructuralIs the word in capital letters?Appearance
PhonologicalDoes the word rhyme with ___?Sound
SemanticIs the word a type of ___?Meaning
Answer the questions naturally. You are not being asked to memorize the words. A memory test will come later.
Prediction

If depth of processing matters, words processed semantically should later be recognized more often than words processed only by appearance.

The surprise recognition phase is intentional: it separates incidental encoding from deliberate memorization.

Study notes & simulation fidelity

  • Sperling (1960): whole- and partial-report logic with a brief visual array. Classic exposures were about 50 ms; cue delay rapidly reduces partial-report advantage.
  • Darwin, Turvey & Crowder (1972): auditory partial report across spatial channels; superiority was present at short indicator delays and decayed over roughly 2–4 seconds depending on the experiment. The optional browser task here uses the related auditory suffix effect instead of pretending to reproduce spatial speech.
  • Miller (1956): “7 ± 2” is presented here as the classic claim students encounter. It should not be treated as a precise modern estimate of a universal STM capacity.
  • Glanzer & Cunitz (1966): this lesson follows the commonly reported Experiment 2 timing: 15 monosyllabic words, each displayed for 1 second with about 2 seconds between words, then immediate or filled-delay recall. The on-screen arithmetic is an adaptation of their counting distractor.
  • Craik & Tulving (1975): structural/phonemic/semantic orienting questions followed by an unexpected memory test. The item set and trial count here are shortened for a classroom.

A browser is not a tachistoscope. Very short visual timings depend on display refresh rate, operating system scheduling, and browser rendering, so this is a teaching simulation rather than laboratory instrumentation.

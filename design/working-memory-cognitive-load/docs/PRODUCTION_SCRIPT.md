# MEMORY QUEST — FULL PRODUCTION SCRIPT

## How to use this document

This is the canonical lesson script. The website should be able to run from it without the teacher needing separate notes.

**Core lesson length:** ~70 minutes.
**Optional animated research interludes:** +10–15 minutes or assign as independent review.

Every chapter uses five kinds of on-screen material:

- **NARRATIVE** — one short scene-setting line.
- **DIALOGUE** — character portrait + JRPG-style text box.
- **CHALLENGE** — student instruction.
- **KEY FACT** — concise psychology content.
- **TEACHER BEAT** — hidden-by-default note for the teacher.

The teacher can always skip a narrative beat without losing the psychology.

# CHAPTER 1 — THE LIMIT OF THE WORKSHOP

## Narrative purpose
Give students a direct experience of capacity failure before naming working memory.

## Psychology purpose
Working memory is a temporary, limited-capacity workspace used for ongoing cognitive tasks.

## C1.1 — Arrival
Background: `mind_archive.jpg`

**NARRATIVE**
> A sealed door waits beneath a row of shifting numbers.

**LYRA — happy**
> “Numbers. Fine. I can remember numbers.”

**SELENE**
> “Then do not theorize yet. Test it.”

---

## C1.2 — Game: Memory Span Gate
**CHALLENGE**
> Watch the sequence. When it disappears, enter the digits in the same order.

Game rules:
- Start at 4 digits.
- Present one digit every ~650 ms.
- Blank screen ~600 ms.
- Student enters sequence.
- Correct → +1 digit.
- Incorrect → one same-length retry with a different sequence.
- End after two failures at the same length or after 9 digits.

Do not show psychological terminology during the task.

---

## C1.3 — Result
Display:
- Longest correct span
- Attempts
- “The point is the pattern, not the number.”

**LYRA — surprised**
> “Okay. That got impossible fast.”

**SELENE — teaching**
> “Not impossible. Limited.”

**KEY FACT**
> Working memory is a temporary mental workspace. It holds and uses information for the task in front of you. Its capacity is limited.

Optional second line:
> It is not simply a storage box; it supports active processing.

### Teacher beat
Ask:
> “What changed as the lists got longer: your motivation, or the amount you had to keep active?”

If someone reaches 9 easily, say:
> “Individual scores vary. The key question is whether performance eventually becomes less reliable as demand increases.”

---

## C1.4 — First sigil
Working Memory sigil lights blue.

**SELENE**
> “The Archive is a workshop, not an infinite warehouse.”

**LYRA — neutral**
> “So if the bench is full, adding one more thing has a cost.”

**SELENE**
> “Exactly.”

**SIGIL GAINED: WORKING MEMORY**

Recap text:
> Limited temporary workspace used to hold and process information.

# CHAPTER 2 — THE ECHO CHAMBER

## Narrative purpose
Orin’s confidence is tested. Introduce a first clean interference effect.

## Psychology purpose
Phonological loop, articulatory rehearsal, articulatory suppression.

## C2.1 — Arrival
Background: `echo_chamber.jpg`

**NARRATIVE**
> The next chamber repeats every whisper a fraction of a second too late.

**ORIN — happy**
> “Words, sounds, sequences. Finally, civilized material.”

**NOVA — neutral**
> “You said the numbers were easy too.”

**ORIN — neutral**
> “Lyra said that.”

**LYRA — concerned**
> “I would like the record to forget that.”

---

## C2.2 — First condition
**CHALLENGE**
> Remember the letters in order.

Use phonologically dissimilar letters based on the course-text replication logic:
F, K, L, M, R, X, Q.

Prototype trial structure:
- 3 practice/measurement lists
- 7 letters each
- display ~5 s total or ~700 ms each
- ~3–5 s short retention interval
- student reconstructs order

**ORIN**
> “If I can keep the sound active, I can keep the sequence active.”

Do not explain “phonological loop” yet.

---

## C2.3 — Suppression condition
A metronome appears.

**SELENE**
> “Again. This time repeat ‘one-two, one-two’ aloud until you answer.”

**ORIN — confused**
> “While memorizing?”

**SELENE**
> “Precisely.”

**CHALLENGE**
> Repeat aloud: 1 – 2 – 1 – 2. Keep pace with the pulse. Remember the letters at the same time.

Use different letter orders.

---

## C2.4 — Result reveal
Two bars:
- Normal recall
- Recall while speaking

If suppression score is lower:
> Interference detected.

If equal/higher:
> Your result was noisy. The research prediction is still that concurrent articulation should reduce verbal rehearsal. Compare class data if available.

**ORIN — frustrated**
> “My inner voice has union rules.”

**LYRA — happy**
> “You finally found a sentence you could not say while saying something else.”

**SELENE — teaching**
> “The phonological loop supports temporary verbal and auditory information. Rehearsal helps keep that information active.”

**KEY FACT**
> Articulatory suppression occupies the rehearsal process. That can reduce ordered verbal recall.

### Teacher beat
Explain the informal replication:
> “Landry and Bartling used seven-letter lists and a repeated ‘1, 2’ suppression task. The course text reports markedly lower recall under suppression.”

Ask:
> “Was saying 1–2 difficult? Why could an easy secondary task still hurt performance?”

---

## C2.5 — Sigil
Phonological Loop sigil glows.

**ORIN — neutral**
> “So verbal expertise does not remove a verbal capacity limit.”

**SELENE**
> “A specialist still has a workspace.”

**SIGIL GAINED: PHONOLOGICAL LOOP**

Recap:
> Temporary verbal/auditory processing supported by rehearsal.

# CHAPTER 4 — TWO HANDS, TWO TOOLS

## Narrative purpose
The first major conceptual reveal: “multitasking” is not a single condition.

## Psychology purpose
Dual-task technique; same-resource interference vs cross-channel coexistence.

## C4.1 — Setup
Background: `map_of_shards.jpg` transitioning to a split screen of Echo Chamber + Map.

**LYRA — neutral**
> “So we have a word system and a spatial system.”

**CAEL — serious**
> “Then the important question is not ‘Can we multitask?’”

**SELENE**
> “Correct.”

**CAEL**
> “The question is: what is competing?”

This line becomes a recurring motif.

---

## C4.2 — Trial A: Spatial + verbal secondary task
Primary task:
- remember 4–5 spatial positions

Secondary task:
- repeat a simple word or short number pair aloud during encoding/retention

**CHALLENGE**
> Track the path while repeating the spoken phrase.

The secondary task should be easy and stable.

Record spatial accuracy.

---

## C4.3 — Trial B: Spatial + spatial secondary task
Primary task:
- same type of spatial sequence

Secondary task:
- alternate tapping/clicking left-right locations or track a moving locator

**CHALLENGE**
> Track the path while also following the moving marker.

Record spatial accuracy.

---

## C4.4 — Compare
Display two condition bars and a small explanatory matrix:

- verbal + spatial → predicted lower interference
- spatial + spatial → predicted higher interference

**NOVA — surprised**
> “The second task was not harder. It just fought for the same kind of space.”

**SELENE — teaching**
> “That is the logic of selective interference.”

**KEY FACT**
> Two tasks may coexist better when they rely on different working-memory resources. Competition increases when tasks draw on the same resource.

---

## C4.5 — Reverse demonstration
Optional quick class trial:
- verbal primary list + spatial tapping
- verbal primary list + verbal suppression

Show expected pattern rather than require many trials.

**ORIN**
> “Spatial tapping bothers me less than filling my own rehearsal channel.”

**CAEL**
> “Different tools. Different bottlenecks.”

### Teacher beat
Critical nuance:
> “Do not turn this into ‘different modalities never interfere.’ Real tasks also share central attention, and complexity matters. The model predicts relative differences in interference, not magical parallel processing.”

Ask:
> “What evidence would distinguish ‘two tasks are hard’ from ‘two tasks use the same resource’?”

---

## C4.6 — Model reveal
The full Working Memory Model appears as a map:
- Central Executive at center
- Phonological Loop
- Visuospatial Sketchpad
- Episodic Buffer locked / dimmed

**SELENE**
> “Now you have earned the model instead of memorizing the diagram first.”

**LYRA — happy**
> “That is annoyingly sensible.”

# CHAPTER 5 — THE GATE OF FOCUS

## Narrative purpose
Introduce executive control through conflict, not definition.

## Psychology purpose
Inhibition, goal maintenance, interference, Stroop.

## C5.1 — Arrival
Background: `focus_gate.jpg`

The gate displays color words in conflicting colors.

**CAEL — confident**
> “The rule is simple. Name the ink color. Ignore the word.”

**LYRA — happy**
> “That seems—”

**CAEL**
> “Do not.”

---

## C5.2 — Baseline
6 congruent/neutral trials.

**CHALLENGE**
> Click the INK COLOR as quickly and accurately as you can.

Record median response time + errors.

---

## C5.3 — Interference trials
12 mixed congruent/incongruent trials.

Use color words red, blue, green, yellow.
Avoid presenting color-blind-dependent alternatives without a text-accessible mode.

Record:
- median congruent RT
- median incongruent RT
- errors by condition

---

## C5.4 — Result
Display:
> Your interference cost: +___ ms

Also show errors.

**LYRA — surprised**
> “I knew the rule. My brain still wanted to read the word.”

**CAEL — serious**
> “Knowing the goal does not make conflict disappear.”

**SELENE — teaching**
> “Executive control helps maintain the task goal, inhibit competing responses, and resolve conflict.”

**KEY FACT**
> Stroop interference is the extra time or errors produced when an automatic response conflicts with the required response.

### Teacher beat
Connect cautiously to the hook video:
> “This gives us a way to study one component of executive control. It does not tell us whether one generation has less executive control than another.”

Ask:
> “What comparison group would you need to make the generational claim properly?”

---

## C5.5 — Research echo
Optional one-line modern connection:
> “Recent research even uses Stroop-style conflict to compare biological and artificial attention systems.”

Do not dwell on AI unless useful to the class.

**SIGIL GAINED: EXECUTIVE CONTROL**

Recap:
> Maintains goals, allocates attention, inhibits competing responses, and helps coordinate tasks.

# CHAPTER 9 — THE THREE LOAD TRIALS

## Narrative purpose
Three-part trial structure. Distinguish kinds/sources of load through direct experience.

## Psychology purpose
Course-text taxonomy: intrinsic, extraneous, germane.

---

## C9A — Intrinsic Load: The Heavy Puzzle
Background: use `overload_engine.jpg` dimmed or clean chamber.

**NARRATIVE**
> The first chamber is empty. The puzzle itself is the weight.

### Trial 1
Simple rule with 2 interacting elements.

Example:
> “If the rune is blue, click its shape.”

### Trial 2
More elements / nested rule.

Example:
> “If the border is blue, classify the inner shape; if gold, classify the number as odd/even; reverse the response if a star is present.”

After each trial, ask 1–9 effort rating.

**NOVA — concerned**
> “Nothing distracted me. The second problem was simply more complex.”

**SELENE**
> “That is intrinsic load: demand inherent in the task itself.”

**KEY FACT**
> Intrinsic load rises when more interacting elements must be processed together, especially for a learner without useful prior knowledge.

Teacher prompt:
> “Would the same task create identical intrinsic load for an expert and a novice?”

Expected answer: no; prior knowledge changes effective complexity.

---

## C9B — Extraneous Load: The Noisy Hall
Background: `noisy_hall.jpg`

**NARRATIVE**
> The next chamber contains an easy task inside a terrible interface.

**CAEL — serious**
> “Ignore the clutter.”

### Clean condition
Simple symbol match with clear single instruction.

### Cluttered condition
Same difficulty, but add:
- irrelevant animated notifications
- redundant labels
- split instructions across opposite corners
- visual decoys
- nonessential sounds (teacher can mute if needed)

Keep task substance matched.

After each condition:
- accuracy
- RT
- effort rating

**ORIN — frustrated**
> “The task did not become more intelligent. The page became more annoying.”

**SELENE**
> “Extraneous load comes from demands that do not help accomplish or learn the task.”

**CAEL — neutral**
> “So ‘focus harder’ is sometimes poor design advice.”

**SELENE — happy**
> “Now you are learning.”

This is Cael’s key character-development beat.

**KEY FACT**
> Reduce unnecessary competition for attention when it does not contribute to learning.

---

## C9C — Germane Load: The Pattern Shrine
Background: `pattern_shrine.jpg`

**NARRATIVE**
> In the final chamber, effort does not disappear. It becomes organized.

### Attempt 1
Present a structured pattern problem without explanation.

### Worked example
Show the underlying schema / relationship visually.

### Attempt 2
New surface features, same deep structure.

After each:
- performance
- effort rating

**LYRA — surprised**
> “I still had to think. But I knew what to look for.”

**SELENE**
> “The course model calls this germane load: mental effort devoted to building and using useful understanding.”

**KEY FACT**
> Not all cognitive effort is a problem. Some effort builds schemas that make future processing more efficient.

### Teacher beat
If desired, add nuance:
> “Later cognitive-load models debate whether germane load is best treated as a separate load type. We are using the taxonomy in your course text.”

---

## C9D — Three-load consolidation
Show three sigils together.

Prompt:
> Which kind of load should instruction usually reduce first?

Choices:
- intrinsic
- extraneous
- germane

Best answer for this framing: **extraneous**, because it is unnecessary to the learning goal.

Then:
> Which kind cannot simply be removed without changing the task itself?

Best answer: **intrinsic**.

Then:
> Which kind represents productive effort in the course model?

Best answer: **germane**.

# CHAPTER 10 — THE DISTRACTED LECTURE

## Narrative purpose
Move from tiny laboratory tasks to actual learning.

## Psychology purpose
Conceptual replication of Sana et al. multitasking logic and application of cognitive load to learning.

## C10.1 — Setup
Background: `mind_archive.jpg` transformed into a lecture alcove.

**ORIN — confident**
> “We understand the system. I can listen and clear a few messages.”

**CAEL — neutral**
> “That sentence has already cost us once.”

---

## C10.2 — Random condition
Randomly assign locally:
- Focus condition
- Multitask condition

Do not make one condition obviously “good” before running it.

---

## C10.3 — Micro-lesson
Use an unfamiliar neutral topic not already taught in the course. Example content in prototype:
> “How medieval semaphore towers transmitted information” or another short factual topic.

Length target: 90–120 seconds in production; prototype can use a shorter reading/audio segment.

### Focus condition
Watch/read uninterrupted.

### Multitask condition
At 15–25 second intervals, display unrelated tasks:
- choose which icon changed
- answer simple calendar question
- click a notification
- remember a short code

Do not make the pop-up task itself difficult. The point is divided processing.

---

## C10.4 — Comprehension quiz
6 short questions.

Record score and mental-effort rating.

If aggregate class mode exists, display both group means after everyone finishes.

---

## C10.5 — Reveal
**SELENE**
> “Sana and colleagues used a similar logic: secondary laptop tasks during a lecture reduced later comprehension.”

**KEY FACT**
> A secondary task can increase cognitive demand during learning even when each task seems manageable on its own.

**LYRA**
> “So multitasking can feel successful because I completed both actions, even if I learned less.”

**SELENE**
> “Completion and learning are not the same outcome.”

### Teacher beat
Ask:
> “What is the dependent variable we actually care about here?”

Push toward comprehension/learning rather than “how busy I felt.”

Then:
> “What confounds would make our classroom version weaker than a proper experiment?”

Potential answers:
- tiny sample
- unequal prior knowledge
- condition awareness
- inconsistent device/audio environments
- very short exposure
- students talking to one another

The Engine has 5 armor segments.
Each scenario removes one segment when the class identifies the mechanism correctly.

Scenario answer flow:
1. Identify the primary system/resource.
2. Identify the source of interference/load.
3. Choose the best redesign.

### Scenario 1 — Verbal collision
> A student listens to spoken instructions while silently rehearsing a seven-digit code.

Expected:
- phonological loop competition
- verbal-on-verbal interference
- externalize code or separate tasks in time

**ORIN**
> “Protect the rehearsal channel.”

### Scenario 2 — Spatial collision
> A student follows a complex diagram while continuously monitoring a moving map in another window.

Expected:
- visuospatial competition
- reduce simultaneous spatial monitoring

**NOVA**
> “A picture can still be crowded.”

### Scenario 3 — Control conflict
> A student must name ink colors while ignoring conflicting written color words.

Expected:
- executive control / inhibition
- Stroop interference

**CAEL**
> “Follow the goal. Ignore the prepotent response.”

### Scenario 4 — Poor instructional design
> A simple task is split across five panels with animations, notifications, and redundant instructions.

Expected:
- extraneous load
- simplify and integrate relevant information

**CAEL — neutral**
> “Control helps. Design decides how much control we must spend.”

### Scenario 5 — Complex but worthwhile
> A difficult new problem still requires effort after distractions are removed, but a worked example helps students recognize the structure.

Expected:
- intrinsic load remains
- worked example / schema support
- productive/germane processing

**SELENE**
> “The goal is not zero effort. The goal is useful effort.”

# TEACHER QUICK RUN — SIGHT-UNSEEN VERSION

If the teacher walks in with only the basics, the site should make the next move obvious.

## Before class
- Open the site.
- Check projector audio.
- Use Campaign Mode.
- Have students use laptops only if individual data are desired; otherwise run tasks whole-class from the projected screen.

## During class
At every **Teacher Beat**, the website can display one sentence beginning:
> SAY:

and one beginning:
> ASK:

The teacher does not need to memorize study procedures.

## If time runs short
Skip in this order:
1. Optional research interludes
2. Story Loom game (keep the 1-minute concept reveal)
3. Switchyard (mention switching cost during Stroop)
4. Individual cognitive-load ratings

Do not skip:
- Digit-span capacity experience
- Articulatory suppression
- Same-resource vs cross-resource interference
- Stroop / executive control
- Extraneous-load demo
- Final synthesis

## If class results contradict the expected pattern
Say:
> “A small classroom demonstration is noisy. The useful question is whether the research design predicts a reliable average difference across many controlled trials.”

Then continue. Never manipulate or hide the class result.

# PRODUCTION COPY RULES

1. No student-facing paragraph should exceed ~55 words.
2. Dialogue should usually be <= 20 words.
3. Technical vocabulary appears **after** the student experiences the effect.
4. Every chapter ends with one sentence students could put in notes.
5. Every study is labeled in teacher mode as:
   - close informal replication
   - conceptual replication
   - demonstration
   - animated study walkthrough
6. Avoid claims that technology or a generation has caused cognitive decline unless evidence actually supports that comparison.
7. Preserve slightly cheesy JRPG tone, but the psychology should remain precise.

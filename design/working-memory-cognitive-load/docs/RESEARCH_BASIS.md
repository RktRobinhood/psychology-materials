# RESEARCH BASIS AND CLASSROOM FIDELITY

This file separates the classroom activities from the evidence they are inspired by.

## Working Memory Model

Baddeley & Hitch (1974) proposed that short-term processing is not a single unitary store. The course text emphasizes dual-task evidence: two tasks drawing on different processing resources can coexist better than two tasks that compete for the same resource.

Course-aligned components used here:
- central executive / executive control
- phonological loop
- visuospatial sketchpad
- episodic buffer (later addition)

## Articulatory suppression — Landry & Bartling (2011)

Classroom use: **close informal replication**.

Course-text procedure:
- seven-letter strings built from phonologically dissimilar letters
- control condition recalls without concurrent speech
- suppression condition repeatedly says "1, 2" while trying to retain the list
- reported mean accuracy in the course text: approximately 76% control vs 45% suppression

The site shortens the number of trials so it fits a lesson. Students should compare conditions, not interpret their absolute score as an individual measure.

## Dual-task / selective interference

Classroom use: **conceptual replication**.

The lesson contrasts:
- verbal + verbal
- spatial + spatial
- verbal + spatial

Prediction: overlap in processing demands should cause more interference than cross-channel pairings. Use this as evidence for specialized working-memory resources, not as proof that cross-channel multitasking is cost-free.

## Stroop interference

Classroom use: **classic demonstration of cognitive control and interference**.

Stroop-style tasks show that naming ink color is typically slower and more error-prone when the printed word conflicts with the color. The American Psychological Association describes the Stroop task as a longstanding paradigm for studying interference and cognitive control.

Reference:
- APA overview of the Stroop effect: https://www.apa.org/research-practice/conduct-research/stroop-effect

## Executive-control hook

The opening video reportedly frames contemporary students as losing executive control. Treat this as a **claim to interrogate**, not a conclusion.

The class can directly experience:
- inhibition cost (Stroop)
- task-switching cost
- distraction cost

It cannot infer a generational decline from one classroom session without historical comparison groups, matched sampling, validated measures, and a much stronger design.

## Sana, Weston & Cepeda (2013)

Classroom use: **short conceptual replication**.

The course text summarizes a lecture-learning study in which laptop multitasking reduced later comprehension, and a second study in which nearby visible multitasking also harmed performance.

The classroom version uses a very short micro-lesson and unrelated browser prompts. It demonstrates how secondary tasks can add load during learning.

## Mani et al. (2013)

Classroom use: **animated study walkthrough only**.

The course text describes financial-salience scenarios and a natural experiment with sugarcane farmers before and after harvest, using Raven's Progressive Matrices and Stroop performance.

Why not replicate live:
- meaningful financial stress cannot be ethically or validly simulated in a few classroom minutes
- the psychological mechanism is contextual and highly confounded in a classroom imitation

Use the animation to discuss operationalization and ecological validity.

## Modi et al. (2019) / surgical overload

Classroom use: **animated walkthrough only**.

The course text describes trainee surgeons performing simulated laparoscopic tasks while fNIRS tracked cortical oxygenation as demands increased. This is valuable for showing physiological approaches to cognitive-load measurement, but is not practical to reproduce.

## Patient KF / Warrington & Shallice

Classroom use: **animated case-study evidence**.

Use it to support the idea that verbal and visual short-term processing can dissociate. Do not turn it into a "game" that trivializes acquired brain injury.

## Cognitive load taxonomy

The lesson follows the user's course text:
- intrinsic cognitive load
- extraneous cognitive load
- germane cognitive load

This taxonomy is therefore kept even though later cognitive-load literature has refined how germane load is conceptualized.

## Measurement

Every cognitive-load mini-game should collect at least two kinds of evidence where possible:
- performance (accuracy / reaction time)
- subjective mental-effort rating

This supports a later discussion that cognitive load is difficult to operationalize and cannot be captured perfectly by one metric.

## Ethical framing

The site should say, in teacher notes rather than interrupting every activity:

> These are informal classroom demonstrations. They illustrate research logic but do not diagnose individual cognitive ability.
